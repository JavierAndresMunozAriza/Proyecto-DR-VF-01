# fence-cloud-lte

Objective: user-drawn geofence sent through the cloud over LTE-M (Thingy:91 X) to the collar, field tests, then the Altium rev. 2 design. Board order target: end of May 2027.
Branch: feat/fence-cloud-lte. Delivery strategy: ask-on-risk. Test runner: plain C99 host tests (`make test` per module), `make cross-check` in `firmware/src/geofence`.
Plan: `/home/xavi/.claude/plans/hola-quiero-mejorar-el-zany-moler-of-0da0a8ad-e5a0-4607-8dfd-0c1991c0c2ec.md` (approved 2026-11-25).

## Specs

- S1: "para mandar la info a la nube sin q el usuario este cerca" - the fence reaches the collar through the cloud, no phone nearby.
- S2: "para elegir los poligonos con el dedo, y q ese poligono se cree en la placa" - the user draws the polygon on a map; the board creates it.
- S3: "como sabes la thingy 91X ya tiene una SIM, creo q es la multioperador, una internacional, se puede probar con ella" - tests run on the Thingy:91 X with its bundled SIM.
- S4: "segun los resultados,se modifica para el diseno de altium" - field results feed the Altium rev. 2 decisions (modem choice, antenna, battery).
- S5: "se buscara el mejor diseno posible y funcional para finales de mayo del 2027 que se mandara hacer la board mas completa" - milestone: best functional design, board ordered end of May 2027.
- S6: "sea igual de compatible con mi diseno fase1 y fase 2, el de altium" - fence format, protocol and core stay the same for the Thingy and the ESP32-S3 PCB; only adapters change.
- S7 (assumption from the plan): fence blob = header + first vertex int32 x1e7 + int16 deltas in 1e-6 degrees, CRC32, max 128 vertices, simple polygon only. See Log L2 for the delta unit.
- S8 (assumption from the plan): nRF Cloud CoAP is the test backend; the final backend is decided before May 2027.
